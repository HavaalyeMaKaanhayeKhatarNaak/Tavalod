جشن تولد بانو فاطیما

روش اجرا:
1) کل فایل ZIP را استخراج کنید.
2) وارد پوشه cat_party_project_v2 شوید.
3) فایل index.html را با Chrome یا Edge باز کنید.
4) همه فایل‌های پوشه assets باید کنار index.html باقی بمانند.

نیازی به نصب Node.js، سرور یا بک‌اند نیست.

تعداد مهمان‌ها: 6 شخصیت متفاوت.
تعداد رقص‌ها: 4 فایل؛ دو رقص قدیمی و دو رقص اضافه‌شده.
زمان‌بندی‌ها: فایل TIMING_GUIDE.txt را ببینید. منطق زمان‌بندی در script.js است.

برای مشاهده روی Android:
ZIP را با ZArchiver یا فایل‌منیجر گوشی استخراج کنید، سپس index.html را با مرورگر باز کنید. اگر مرورگر اجازه اجرای فایل محلی یا رسانه‌ها را نداد، از یک اپ Local Web Server استفاده کنید و پوشه استخراج‌شده را به‌عنوان ریشه سرور انتخاب کنید.
